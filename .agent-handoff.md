## Acceptance Criteria
1. Install `@upstash/redis` (production dependency) and `@vercel/node` (dev dependency).
2. Create `api/storage.ts` serverless handler for Vercel:
   - Reads `submeter:app_data` from Upstash Redis via `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.
   - `GET /api/storage`: returns `{ exists: true, data }` or `{ exists: false }`.
   - `POST /api/storage`: validates `units`, `meters`, and `billingCycles`, then sets `submeter:app_data`.
3. In `vercel.json`, update SPA rewrites to ensure `/api/(.*)` requests are not redirected to `/`.
4. In `vite.config.ts`, implement dev middleware for `/api/storage` that queries Upstash Redis using the `.env.local` credentials and also saves a local backup in `data/submeter-data.json`. Add `data/` and `.env*` to `.gitignore`.
5. In `src/services/storage.ts`:
   - Add `fetchCloudAppData()` and `pushCloudAppData()`.
   - On initial load / restore: if local storage has valid billing cycles and Upstash is empty or has fewer cycles, auto-push local data to Upstash. If Upstash has data and local is empty/sample, populate local IndexedDB and LocalStorage and dispatch `notifySyncListeners()`.
   - In `saveAppData()`, synchronously save to IndexedDB and LocalStorage as before, and debounce a background push to `/api/storage`.
   - Gracefully handle offline errors so PWA offline functionality is never blocked.
6. In `src/components/settings/LandlordSettingsModal.tsx`, add a Cloud Sync status indicator and a manual "Sync Now" button.
7. Verification: `npm run build` passes with 0 errors.
